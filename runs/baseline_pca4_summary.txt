## Conclusion (before Phase 8)

1. **PCA4 can pass SC-001–SC-003 in a clean session, but performance is not repeatable yet** — Session B meets all single-run MVP thresholds (10/15 keys, 80% row, 44 px median). Sessions A and C fail the same thresholds with no code changes between runs.

2. **Current spread is 20% → 67% key-hit, which fails SC-004 repeatability** — Three manual runs span 47 percentage points on key-hit (20%, 40%, 67%), well above the 20 pp SC-004 limit. Row accuracy spans 40%–80%. Median error spans 44–85 px. Session C (6/15, 61 px) sits between the degraded floor and clean reference, confirming instability rather than a single bad outlier.

3. **The next Phase 8 direction should consider repeatability / calibration collection / posture stability before aggressive mapper changes** — Session C had the best supplementary LOOCV (55.2 px) and fewest quality warnings (6) yet still scored 6/15 — benchmark outcome decouples from fit metrics when collection/posture varies. Prioritize fixation gates, head-drift enforcement, and collection consistency (T033 collection iteration) over PCA4/ridge tuning (T035) until key-hit spread narrows.
