## B. `eye_box_h` block analysis (T033 usability)

### Symptom summary (Phase 8)

| Phase | Layout | Cal attempts | `eye_box_h` hard-fail | Block rate |
|-------|--------|--------------|----------------------|------------|
| T061 | keyboard15 | 2 | 0 | **0%** |
| I01 | keyboard_full9 | 3 benchmarked | 0 | **0%** |
| I02 | keyboard_edge15 | 4+ | ≥1 (`8737c34297b1` span 0.0053) | **≥25%** |
| **I03** | keyboard_full9 + T035 | 4 | 2 (`dccd8029cc9c` 0.0047; `4f4f6b6d6542` 0.0040) | **50%** |

Blocked sessions collected **9/9 or 15/15 targets**; failure is **post-collection** quality gate at mapper finish.

### How the gate works (two layers)

| Layer | When | Threshold | `eye_box_h` meaning |
|-------|------|-------------|---------------------|
| **Fixation gate** | Per target during collection | `CALIB_HEAD_DRIFT_EYE_H = 0.003` vs point baseline | Instantaneous drift within one fixation |
| **Session quality** | After fit | Span max−min of per-target mean `eye_box_h` | **>`0.004`** triggers message; hard-fail if `max_head_drift_eye_h` param set |

**Measurement** (`gazekey/features/extractor.py`): `eye_box_h` = mean of left/right eye **contour bbox height** in normalized face coordinates — not a direct cm distance reading.

### Root-cause assessment

| Hypothesis | Evidence | Verdict |
|------------|----------|---------|
| **Real head-distance drift** | Per-target fixation gate (0.003) passed on all blocked sessions; user completed all anchors | **Unlikely sole cause** — large physical lean would often fail per-target gate |
| **Layout-induced / gaze-coupled sensitivity** | Blocks cluster on **full9** (bottom band y≈373) and **edge15** (y 169–373); **T061 keyboard15** (y 169–305) **0%** blocks; vertical span +50% on wide layouts | **Primary factor** — looking at Ctrl/Space/Enter row changes head pitch and eye landmark bbox size; same class as demoted `face_x`/`face_y` session span |
| **Gate threshold / reporting bug** | `MAX_HEAD_DRIFT_EYE_H = 0.0045` in `config.py` is **not** passed to `analyze_head_pose_drift()`; span compared to hardcoded **`warn_eye_h = 0.004`**; fail message always says `> 0.0040` even when config says 0.0045; `4f4f6b6d6542` failed at **0.0040 = threshold** (boundary / float tie) | **Contributing factor** — effective threshold **stricter than documented**; boundary failures are brittle |
| **Asymmetric policy vs face_x** | `face_x`/`face_y` session span → **warning** for `keyboard*` modes; `eye_box_h` span → **hard fail** | **Policy inconsistency** — wide layouts penalized twice for gaze-correlated geometry |

### Conclusion (T033 recommendation direction — do not implement yet)

1. **Not primarily “user moved closer to camera”** — collection completed; per-target gate already passed.
2. **Primarily layout + measurement coupling** — bottom-row anchors on full9/edge15 inflate session `eye_box_h` span via pitch/gaze/landmark effects.
3. **Partly gate design** — threshold mismatch (0.004 vs 0.0045), boundary ties, and keyboard `face_x` demotion not applied to `eye_box_h`.

### When T033 is approved (future single lever — options ranked)

| Option | Type | Pros | Cons |
|--------|------|------|------|
| **B1** | Demote `eye_box_h` session span to **warning** for `keyboard*` (parallel `face_x`) | Fast usability win; matches wide-layout rationale | Less session-level head-drift protection |
| **B2** | Wire `max_head_drift_eye_h` into `analyze_head_pose_drift(warn_eye_h=…)` | Fixes config/behavior mismatch | May still block full9 if threshold stays 0.0045 |
| **B3** | Layout-aware span threshold (wider for full9/edge15) | Targets root cause | More complex; needs artifact-backed limits |
| **B4** | Persist per-target `eye_box_h` in `calibration_debug.csv` | Better diagnosis before changing threshold | Instrumentation only; not a fix alone |

**Recommended T033 lever (when implemented)**: **B1 + B2** together — align policy with `face_x` demotion **and** fix threshold wiring; validate with 4+ full9 cal attempts aiming &lt;25% block rate.

### Diagnostic command (before changing gates)

Re-run one full9 cal with verbose logging; inspect `[calib] head geometry span: … eye_box_h=…` and per-target `eye_h` table. Compare top-band (q) vs bottom-band (Ctrl/Space) targets.
