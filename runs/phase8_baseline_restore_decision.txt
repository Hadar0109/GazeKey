# Phase 8 Baseline Restore Decision

**Date**: 2026-06-10  
**Feature**: 001-calibration-mapping-mvp  
**Task**: T062d — restore T061 safe baseline before further tuning

---

## Decision

Restore active runtime behavior to the **T061 two-run safe baseline**. Phase 8 layout
and row-Y bias experiments are **historical evidence only**; they are not the active
comparison baseline for future one-change investigations.

---

## Evidence summary (why restore)

| Experiment | Layout | Change | Outcome |
|------------|--------|--------|---------|
| T061 (A/B) | `keyboard15` | none (frozen) | **6/6 key-hit**, Z/C **4/4** — reference |
| I01 `keyboard_full9` | 9 edge anchors | T032 layout | Some edge keys helped; **Z/C regressed**; unstable across runs |
| I02 `keyboard_edge15` | 15 hull coverage | T032 layout | Hull covered; **benchmark accuracy regressed** |
| I03 letter-row row-Y | `keyboard_full9` / `keyboard15` | T035 fit | **Did not validate**; Z/C regressed on keyboard15 sanity |

**Conclusion**: No Phase 8 change produced stable, net benchmark improvement vs T061.
Continuing to tune on top of experimental code would confound follow-up investigations.

---

## What was reverted (active code)

| Area | Reverted behavior |
|------|-------------------|
| Default layout | `keyboard15` (no `keyboard_full9` / `keyboard_edge15` default) |
| Row-Y bias | Legacy `calibration_row_groups` band means; mean anchor Y per grid band |
| Row assignment | Nearest calibration grid-band center (not letter-row Q/A/Z bands) |
| Gap targets | Original T061 inclusion in row-bias fit (grid-band grouping) |
| T035 letter-row | Removed from active `fit_calibration_mapper` / `compute_row_y_residuals` |
| Quality gate | Session `face_x`/`face_y` drift restored as hard reject on keyboard layouts |
| `keyboard_edge15` | Removed from active `keyboard_geometry_targets` modes |
| `_band_candidate_rows` | Removed (full9 band-row filter from T061D) |
| Mapper runtime | Removed `keys=` pass-through for letter-row Y centers |

**Not changed**: α policy, feature smoothing, fixation gate thresholds, hitboxes,
benchmark thresholds, PCA4-only mapper path.
