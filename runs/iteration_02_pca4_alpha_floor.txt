## Outcome verdict: **PARTIALLY IMPROVED**

### Improved
- **Best key-hit** rose from 5/15 (Iter 1) to **7/15** (+2 keys); vs baseline degraded
  sessions (3/15, 6/15) and approaching baseline Session C (6/15).
- **SC-004 repeatability** on key-hit: **7 pp spread** (40%–47%) — within the ≤ 20 pp
  limit across three benchmark-completed runs.
- **Median error** on best run: 55.4 px — essentially at the 55 px threshold (failed by
  0.4 px only on key-hit / row gates).
- **ridge_alpha=0.5** on best run shows extended grid can select below the old 1.0 floor.

### Unchanged / not improved
- **SC-001–SC-003**: 0/3 benchmark runs passed; capability bound (Session B 10/15, 44 px)
  not reproduced.
- **Row accuracy** still far below 80% on all runs (40%–53%).
- **Failure cause** remains mapping (`likely_cause=mapping` on all three); common miss
  cluster: E, A, J, Z, B, M, Space.

### Regressed (minor)
- **Ceiling vs baseline**: no run reached baseline Session B (10/15); peak 47% vs 67%.
- Runs 2–3 with **ridge_alpha=1.0** scored 6/15 — same as baseline Session C tier, not
  better than Iter 1 best when α stayed at old floor.

## Conclusion

T035 iteration 2 (lower `MIN_ALPHA` + extended `ALPHA_GRID`) **raised the floor and
narrowed spread** versus Iteration 1 and T029 instability, and produced the best
post-Phase-8 benchmark so far (**7/15**, median 55.4 px with α=0.5). It did **not**
restore baseline Session B (10/15) or achieve a full CQ-1 pass.

LOOCV α selection varied (0.5 vs 1.0) without a clear monotonic “lower α = better” rule
across sessions — further PCA4 α tuning alone is weak justification for Iteration 3.

**Phase 8 checkpoint:** SC-001–SC-003 not met; SC-004 key-hit spread met on this
3-run sample. **Do not start Iteration 3 without explicit approval and updated
failure-pattern review.**

**Next planning options** (not executed):
- T032: reduce calibration layout density if head-travel / target fatigue suspected
- T034: geometry verification if preview-on-key looks better than benchmark scoring
- T033 follow-up: per-target fixation tightening (if cal quality warnings correlate with misses)
- T035 follow-up: only if a stable α band emerges from more runs — evidence mixed this cycle
