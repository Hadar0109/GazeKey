## 4. Manual live gate — REQUIRED (camera)

Run **one** full calibrate → preview → benchmark session after T052–T058. Record results in §5.

### PowerShell (single session)

```powershell
cd "C:\Users\Lenovo\Desktop\Virtual Keyboard"

# Optional: extra terminal detail
$env:GAZEKEY_VERBOSE = "0"

# Developer benchmark auto-start after preview (CQ-3)
$env:GAZEKEY_DEV_BENCHMARK = "1"

# Default layout keyboard15 — do NOT set GAZEKEY_CALIB_MODE unless debugging
Remove-Item Env:GAZEKEY_CALIB_MODE -ErrorAction SilentlyContinue

python main.py
```

### Manual checklist (during run)

1. **Launch** — app starts; fixation overlay shows dot + progress only (no camera preview window by default).
2. **Calibrate** — complete all 15 targets; wait for pass/fail after session ends.
   - Terminal must show: `[calibration] PASSED` or `[calibration] FAILED`
   - Layout must be `keyboard15`
   - File written: `runs/calibration_<session_id>.txt`
3. **Preview (read-only)** — after calibration pass:
   - Gaze preview dot tracks keys
   - **Must NOT happen**: key highlight selection, dwell progress, text buffer changes
4. **Benchmark** — auto-starts without UI button:
   - Complete 15 highlighted keys (look at each until it advances)
   - Terminal must show: `[benchmark] PASSED` or `[benchmark] FAILED` with `keys=`, `row=`, `median_err=`
   - File written: `runs/benchmark_<session_id>.txt`
5. **Mapper confirmation** — in calibration finish output or `runs/calibration_*.txt`:
   - `mapper_type=pca4_baseline` or `SELECTED mapper_type=pca4_baseline`
   - No `row_aware`, `idw_`, or v1 `CalibrationSession` messages

### Optional verbose diagnostics

```powershell
$env:GAZEKEY_VERBOSE = "1"
$env:GAZEKEY_DEV_BENCHMARK = "1"
python main.py
```
