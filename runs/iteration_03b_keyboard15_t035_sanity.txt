## Decision

| Question | Answer |
|----------|--------|
| Did T035 regress **T061 overall** key-hit? | **No** — 6/6/8 vs 6/6; best run **8/15** |
| Did T035 regress **T061 Z/C** (P0)? | **Yes** — **4/4 → 1/6**; Z **0/3** |
| Is T035 validated safe on `keyboard15`? | **No** — P0 failed |
| Revert T035 entirely? | **Not yet mandatory** — headline improved on S3; Z/C failure may be gap-bias + α confound |
| Recommended next step | **Do not** treat T035 as baseline-safe; before T033 or full9 work, either **(a)** patch T035 to exclude `grid_row=-1` gap targets from row-bias fit and re-sanity Z/C, or **(b)** one keyboard15 run with T035 reverted to legacy row groups to isolate lever |

**Summary**: **Partial regression** — T035 (or code shipped with it) **broke T061 Z/C reliability** while **not** degrading mean key-hit. Sanity **does not clear** T035 for default layout.
