# Contract: Run Summary

**Version**: 1.1.0  
**Feature**: `001-calibration-mapping-mvp`

## Purpose

Answer: **what happened, and did calibration/mapping pass or fail?** (Constitution VII)

## Interface (logical)

```text
RunSummaryWriter
  write(summary: RunSummary) -> None
  format_console(summary: RunSummary) -> str

RunSummary
  session_id: str
  run_type: calibration | benchmark
  status: passed | failed
  primary_metrics: dict
  failure_reason: str | null
  timestamp: ISO-8601
```

## Console format (minimum)

**Calibration**:

```text
[calibration] PASSED session=<id> layout=keyboard15 targets=15/15 ...
[calibration] FAILED session=<id> reason=...
```

**Benchmark**:

```text
[benchmark] FAILED session=<id> keys=8/15 (53%) row=12/15 median_err=62px
[benchmark] PASSED session=<id> keys=11/15 (73%) row=13/15 median_err=48px
```

## Persisted format (minimum)

One folder per session — `runs/<session_id>/`:

| File | When |
|------|------|
| `calibration_summary.txt` | Calibration finish |
| `benchmark_summary.txt` | Benchmark finish (includes `failure_analysis` block) |
| `coverage.json` | Calibration finish |
| `benchmark_diag.json` | Benchmark finish (optional detail) |
| `calibration_v2.json` | After ridge fit (inspection snapshot) |

| `runs/t061_baseline_comparison.md` | T061C — **active** two-run baseline comparison (human-written) |
| `runs/iteration_NN_<change>.txt` | Per tuning cycle vs T061 (T036) |
| `runs/baseline_pca4_summary.txt` | T029 — **historical only** |

Aggregated comparison files are not auto-generated by `RunSummaryWriter`.

## Verbose mode

When `GAZEKEY_VERBOSE=1`:

- Per-target calibration detail
- Per-key benchmark detail

Default **off** — normal runs stay quiet.

## Thresholds (CQ-1)

Defined in `gazekey/evaluation/run_summary.py` → `BenchmarkThresholds`:

- `min_keys_correct`: 10 (of 15)
- `max_median_error_px`: 55.0
- `min_row_accuracy`: 0.80
- SC-004: `min_session_floor_keys`: 8; `max_session_spread_fraction`: 0.20 (evaluator TBD)

## Acceptance (SC-005)

A tester can state pass/fail and primary metrics from console output or
`runs/<session_id>/` summary files without reading verbose logs.
